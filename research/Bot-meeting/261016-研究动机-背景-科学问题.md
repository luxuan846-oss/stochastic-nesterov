# 随机 Fast KM 的噪声门槛：研究背景、动机与科学问题

2026-10-16，Booming 讨论后整理。英文问题稿见 `261016-question-for-Bot.md`。标「已推导」的是我们在具体例子上的计算；标「待证」的是研究目标，不是结果。

## 1. 研究背景

**确定性 Fast KM。** Boţ–Nguyen（SINUM 2023）对 $\theta$-averaged 算子 $T$ 提出 Fast KM，参数 $\alpha>2$、$0<s\le1/\theta$，得到残差 $\lVert x_k-Tx_k\rVert=o(1/k)$ 与迭代点弱收敛。取 $s=1$ 时（原文式 (2.8)）

$$
x_{k+1}=a_kx_k+\frac{\alpha}{2(k+\alpha)}T(x_k)+\frac{k}{k+\alpha}\bigl(T(x_k)-T(x_{k-1})\bigr),\qquad a_k=\frac{k+\alpha/2}{k+\alpha}.
$$

加速来自最后的外推项。对非扩张 $T$（$\theta=1$），$s=1$ 是允许的最大步长（原文 Remark 2.1）。

**随机实现。** 每次计算 $T$ 都带噪声：$\widehat T_k(x_k)=Tx_k+e_k$，$\mathbb E[e_k\mid\mathcal F_k]=0$，方差 $\sigma_k^2$。自然的实现是把上一步的带噪值存下来复用，每步只新查询一次。AFP 与标准随机 Nesterov 也属于这种复用型递推。

**噪声为什么必须衰减。** 最新噪声 $e_k$ 在 $x_{k+1}$ 中的系数趋于 1。方差不衰减时，残差停在噪声量级（roadmap §7.2）。让步长递减也能压噪声，但 Fast KM 的 $o(1/k)$ 需要常数步长：可和的 $s_k$ 连无噪声收敛都会破坏，不可和的递减步长会拖慢速率（随机 Nesterov 的对应结果见 Attouch–Fadili–Kungurtsev，JOTA 2026，Remark 3.2）。因此固定 $s$，用 batch 让方差衰减：$b_k\approx k^q$ 给出 $\sigma_k^2\approx k^{-q}$。

**已有结果。** 相近的随机加速不动点方法已有几乎必然 $o(1/k)$：VR-FKM（arXiv 2406.02413）、VAPEG（arXiv 2508.16791，Cor 3.4）、AFP（arXiv 2512.13547）。条件都是 $\sum_kk^2\sigma_k^2<\infty$ 一类，即 $q>3$，batch 至少按 $k^3$ 增长。原始复用 Fast KM 在这一条件下对一般 $T$ 的结论，我们尚未证完。期望意义下，随机 iKM（Yang 等，arXiv 2609.28543）在预设终止步数时达到近最优样本复杂度，目标与固定参数的整条轨道不同。

## 2. 研究动机

**门槛 3 混合了几种来源。** 我们在两个例子上算出几乎必然门槛（已推导）：

| 噪声假设 | $T=0$，$s=1<1/\theta$ | $T=-I$，$s=1=1/\theta$ |
|---|---|---|
| 只知道方差 | 3（稀有大误差反例） | 3 |
| Gaussian | **2** | 3 |

- $T=0$ 时，复用让同一份旧噪声在相邻两步中抵消；$\alpha=4$ 时精确有 $(k+2)(k+3)x_k=12x_1-4e_0+2\sum_{j=1}^{k-2}e_j+(k+1)(k+2)e_{k-1}$。
- $T=-I$、$s=1/\theta$ 时，奇偶子列分离，抵消失效。

所以 $q>3$ 这一要求，一部分来自偶尔出现的大误差（噪声假设），一部分来自步长取在上限（算法参数），剩下的可能来自证明方法。

**对领域研究者的意义。** 把三种来源分开，研究者就知道该在哪里使劲：控制噪声尾部、给步长留余量，还是改进证明。三者都处理好时，batch 可从 $k^3$ 降到 $k^2$，每步少用一个 $k$ 倍的样本。对做连续时间动力系统与加速算法的读者，这也指出能量（Lyapunov）方法的一个盲点：它把每一步的噪声分开计价，看不见相邻两步之间的抵消。

**与 oracle 成本的关系。** 常数步长下 N6 要求 batch 增长快于 $k^3$。门槛若降到 2，batch 降到 $k^{2+\omega}$，每步少一个 $k$ 的量级。但 $q>2$ 仍要求方差衰减，每步仍要多个 oracle，没有做到每步一个 oracle。每步一个 oracle 对应 N2：常数步长下残差不趋于零，递减步长下回到较慢的随机逼近速率（JOTA 2026 Remark 3.2），属于另一个问题。

## 3. 科学问题

**主问题。** 复用型随机 Fast KM 在 $\sigma_k^2\asymp k^{-q}$ 下，几乎必然 $o(1/k)$ 的门槛是多少？它怎样依赖噪声假设，以及步长 $s$ 与 $1/\theta$ 的关系？

**已知与未知（一般 $T$）：**

| $q$ 的范围 | 结论 | 依据 |
|---|---|---|
| $q\le2$ | 不够 | $T=0$、Gaussian 时已失败 |
| $2<q\le3$，只知道方差 | 不够 | $T=0$ 稀有大误差反例 |
| $2<q\le3$，Gaussian，$s=1/\theta$ | 不够 | $T=-I$ |
| $2<q\le3$，Gaussian，$s<1/\theta$ | **未知** | $T=0$ 成立，一般 $T$ 待证 |
| $q>3$ | 相近递推已有；原始复用版本待证 | AFP、VAPEG |

**子问题：**
1. **基础**：原始复用 Fast KM 在 $\sum_kk^2\sigma_k^2<\infty$ 下，对一般 $\theta$-averaged $T$ 得到 $o(1/k)$ a.s. 与迭代点弱收敛（待证；卡在能量不等式中旧噪声 $e_{k-1}$ 的线性项）。
2. **主问题**：Gaussian（或次高斯）噪声、$s<1/\theta$、$2<q\le3$ 时，对一般 $T$ 是否成立（待证；先做均方，先做仿射算子）。
3. **边界**：$s=1/\theta$ 时，$q>3$ 在非扩张类上不能改进（$T=-I$ 已推导，待写成完整证明）。

概率工具限于 Borel–Cantelli、鞅收敛（含 Robbins–Siegmund）与 Kronecker 引理。

## 4. 风险与第一步

**风险。**
- 非线性 $T$ 可能破坏抵消，主问题的答案可能是否定的；这时需要找出破坏抵消的算子结构。
- Gaussian 假设可能被认为过强。
- 新颖性待查：随机 Nesterov 写成外推序列时自动是复用形式，相关文献可能已利用这种抵消。

**第一步（一到两周）。**
1. 亲手推导 $T=-I$、$s=1$ 的奇偶分离与门槛 3。
2. 取二维仿射 averaged 算子（如缩放旋转），在 $s<1/\theta$ 下检验 Gaussian 门槛是否为 2。

## 附：为什么不做其他方向（讨论过程记录，2026-10-15 至 10-16）

| 方向 | 不做的原因 | 谁决定 |
|---|---|---|
| 加性噪声下靠 batch 恢复速率本身 | 渐近设定下 batch 可任意增大，只是误差可和的确定性分析；VR-FKM、AFP、VAPEG 已做 | 用户 |
| 噪声形式复杂（耦合、嵌套、KKT 中的噪声）作卖点 | 困难不等于重要 | 用户 |
| 约束优化 / KKT、决策依赖分布、嵌套近端模型 | 当前只关心最简单的随机模型 | 用户 |
| 按样本数计的渐近速率（ML 会议路线） | 目标 venue 为 SIOPT / SINUM / FoCM，期刊看重结论的完整与条件的精确 | 用户 |
| 以噪声尾部作主卖点 | 偏概率；保留为定理的一个条件，不作卖点 | 用户 |
| 重查作为实际做法 | 无人使用，只作对照 | 用户指出 |
| 递减步长代替 batch | Fast KM 的 $o(1/k)$ 需要常数步长；递减步长是另一个问题（`gap:anytime_path`），速率更慢 | 讨论结论 |
| 只做均方 | 用户偏好几乎必然，概率工具直接用 | 用户 |
| 只证 $q>3$ 充分性 | 与 AFP 结论接近，单独作为 SIOPT 贡献偏弱 | 10-14 覆盖核查 |

**留下的方向：** 复用型随机 Fast KM 的几乎必然门槛。它有正面的主问题（次高斯、$s<1/\theta$ 下 $q>2$），有三个已推导的例子说明条件 sharp，用户的工具与能力够得着，且已在 $T=0$ 上亲手验证过。
