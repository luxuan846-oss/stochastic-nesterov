# 随机 Fast KM 证明的限定范围复核

2026-10-14。核查对象为同目录 `261014-stochastic-fast-km-proof.md` 中的能量展开、P1–P4、递减步长反例，以及 AFP v1 的 Lemma 1 反例。本记录没有审阅所有引用论文的完整证明，也不认证候选课题的新颖性。

**精华总结。** 在下述明确假设下，未发现双查询命题 P1 的实质证明错误。复用查询与双查询的 Gaussian 阈值计算正确。AFP v1 的反例确实否定其按印刷形式陈述的 Lemma 1 式 5；它没有否定该论文 Theorem 2 的结论。

**结论。** P1 可作为独立重建的证明基准。原复用查询版本在一般 N6 下的结论，仍应标记为待证明。复核提出的表述问题已修订：数值矩表现称为标准差，P3–P4 的初值条件已明确，P1 的期望界常数范围已补足。限定范围内没有尚未处理的实质证明错误；这不等于一般复用查询定理已经成立。

## 1. 核查依据

1. Boţ–Nguyen，arXiv:2206.09462v2，Algorithm 2.1、式 2.7，Section 3 的能量，Lemmas 3.1–3.2，Proposition 3.3，以及 Appendix B 中 Lemma 3.1 的推导。
2. Nguyen-Trung–Tran-Dinh，arXiv:2512.13547v1，AFP 初始化与更新，能量式 3、参数式 4、Lemma 1 式 5，以及 Appendix B.1 的 Young 参数选择。
3. 本次推导的闭式解和已保存的有理数计算；数值记录只用于检查代数实现，没有替代路径极限的数学论证。

本次检查检测的具体失败包括：能量并非正定、原下降关系依赖更早的确定性轨道、条件线性项不能消除、little-o 推导缺少极限、闭式解系数错误、AFP 参数不满足原引理条件。若发现其中任一问题，相应定理或反例必须降级为待证明。

**复核方法。** 曾向 Codex MCP 的 `gpt-5.5`、`xhigh` 推理配置提交完整证明。该调用在 300 秒后超时，没有收到外部审阅结论。随后由独立审阅 agent 阅读完整附录及上列原文，完成本记录所述的限定范围核查。因此，可以报告独立审阅结果，不能报告外部跨模型复核通过。

**依赖与假设。** P1 使用 Hilbert 模型及 cocoercivity、原文局部下降、正定能量和精确扰动恒等式，继而使用 Robbins–Siegmund、Tonelli 和路径 Opial。P2 使用同一个局部下降与能量范数，以路径绝对可和替代条件零均值。P3 使用复用查询的闭式解、Gaussian 尾界和鞅级数。P4 的必要性使用独立 Gaussian 方差，充分性使用 P1。递减步长反例和 AFP 反例分别只使用确定性递推和原文能量代入，没有反向使用待证明的一般复用 N6 定理。

关键类型为：$x_k,e_k,f_k\in H$，$v_k,u_k$ 是确定的非负实数，$\mathcal F_k$ 是查询前的信息，$E_{\lambda,k}$ 是非负实随机变量。原 Fast KM 中 $s$ 是固定步长；AFP 反例中的同名 $s$ 是另一篇论文的参数。P3–P4 的等价阈值只对指定 Gaussian 模型、固定确定初值及 $n\to\infty$ 成立，不具有对一般算子或一般噪声分布的统一性。

## 2. P1 的逐项核查

| 项目 | 核查结果 | 条件与理由 |
|---|---|---|
| 原算法的 $V=I-T$ 写法 | 通过 | $b_k=s(k+\alpha/2)/(k+\alpha)$，$c_k=sk/(k+\alpha)$，与原式 2.7 展开一致 |
| 展开能量 | 通过 | 原平方表达式展开后恰得附录中的二次型；所有残差与速度交叉项保留 |
| 正定性 | 通过 | $1<C_\alpha<2$；$(d,w)$ 子块行列式为 $C_\alpha(2-C_\alpha)>0$；Schur complement 为 $2\lambda(\alpha-1)-4\lambda^2/C_\alpha>0$ |
| 参数区间 | 通过 | $\alpha=4$ 时原 Lemma 3.2 的区间为 $(5/3,5/2)$；$2$ 与 $9/4$ 均在其中 |
| 局部下降 | 通过 | 原 Appendix B 的代数仅使用当前两个点、算子值和当前更新；不要求此前每一步均无噪声 |
| 明确下降常数 | 通过 | $\omega_1=4(\lambda-3)$、$\omega_4=-10/3$，$\rho=\sqrt{9/10}$；附录 $D_{\lambda,k}$ 的各项常数与原 Proposition 3.3 推导一致 |
| 精确扰动恒等式 | 通过 | 下一状态改变为 $(r+\eta,d+(k+1)\eta,w)$；二次型的线性系数为 $L_{\lambda,k}$，平方系数为 $Q_{\lambda,k}$ |
| 条件线性项 | 通过 | 双查询时，虚拟下一步与 $L_{\lambda,k}$ 在查询前可测，整体 $\eta_k$ 条件零均值 |
| Robbins–Siegmund | 通过 | 能量非负、适应且可积；确定的方差预算保证 $\sum Q_{\lambda,k}a_k<\infty$；下降量非负 |
| 实际速度平方可和 | 通过 | Tonelli 给出 $\sum k^2\lVert\eta_k\rVert^2<\infty$ 几乎必然，再将实际速度写为虚拟速度加扰动 |
| little-o 残差 | 通过 | 两组能量极限给出 $p_k$ 极限；正定 $h_k$ 有极限且 $\sum h_k/k<\infty$，因此 $h_k\to0$ |
| 距离极限 | 通过 | 见下一段的直接论证，避免额外引理 |
| 几乎必然弱极限 | 通过 | 在可分 Hilbert 空间，对解集可数稠密子集取得共同概率一事件；距离极限、demiclosedness 与路径 Opial 足够 |
| 期望平方残差界 | 通过 | 需要确定或可积的总方差预算；仅有路径上预算有限不能自动得到统一期望界 |

距离极限可直接从已经证明的量推出。记 $r_k=x_k-x^\star$、$d_k=k(x_k-x_{k-1})$、$w_k=skV(x_{k-1})$。由有界性与 little-o 证明，$r_k$ 有界，$d_k,w_k\to0$。又有

$$
p_k=\frac{\alpha-1}{2}\lVert r_k\rVert^2+\langle r_k,d_k+w_k\rangle.
$$

第二项趋于零，而 $p_k$ 有极限，故 $\lVert r_k\rVert^2$ 有极限。证明附录已采用这个直接论证，删除了原来不再需要的 $F_k,q_k$ 和 Lemma A.2 调用。

P1 的期望界常数应理解为依赖于相对于某个固定解的初始二阶矩、固定参数和总方差预算。它不应被解释为对所有问题实例统一的常数。

## 3. 原复用查询与 P2

复用查询时，$e_{k-1}$ 已属于当前信息。项 $-c_k\langle L_{\lambda,k},e_{k-1}\rangle$ 的条件期望不能按新的 martingale difference 消除。附录保留该项是正确的。

本次没有从这一证明缺口推断 N6 无效。对更强条件 $\sum k\lVert e_k\rVert<\infty$，正定能量平方根的三角不等式先给出有界性；随后 $\lVert L_{\lambda,k}\rVert\le Ck\sqrt{E_{\lambda,k}}$ 给出绝对可和的能量扰动。该路线支持 P2。

P2 不要求误差条件零均值。它的条件强于平方加权方差可和，因此不能用于回答原复用算法的一般 N6 问题。

## 4. 两个 Gaussian 阈值

对 $T=0,s=1,\alpha=4$，逐步展开得

$$
x_n=\frac{12x_1-4e_0+2\sum_{j=1}^{n-2}e_j+(n+1)(n+2)e_{n-1}}{(n+2)(n+3)}.
$$

这里同一个历史误差的两个系数相减为 $2$，与原递推一致。若 $e_j=\sigma(j+1)^{-q}Z_j$ 且 $Z_j$ 独立标准 Gaussian，则 $q>1$ 时，鞅级数与 Gaussian 尾界给出 $n x_n\to0$ 几乎必然。$q\le1$ 时，最后一个独立误差造成的 Gaussian 方差下界排除依概率趋零，因此也排除几乎必然趋零。

双查询对应的精确解为

$$
x_n=\frac{12x_1+\sum_{i=1}^{n-1}(i+2)(i+3)e_i-\sum_{i=1}^{n-1}i(i+3)f_i}{(n+2)(n+3)}.
$$

独立性给出对 $0\le q<5/2$ 的方差渐近式

$$
\operatorname{Var}(x_n)\sim\frac{2\sigma^2}{5-2q}n^{1-2q}.
$$

由此 $q\le3/2$ 时没有目标 little-o；$q>3/2$ 时满足 P1 条件。因此 P3–P4 的阈值比较正确。结论只覆盖该 Gaussian 模型，不能推广为一般非线性算子或只有二阶矩控制的所有误差。

**数值记录的表述，已修订。** `reuse_and_afp_results.json` 的 `exact_standard_deviations` 计算 $n\sqrt{\operatorname{Var}(x_n)}$。主报告将该指标称为标准差，脚本和记录字段统一为 `n_times_sd_reuse` 与 `n_times_sd_fresh`。当 $x_1=0,\sigma=1$ 时，这些数值也等于 $n$ 倍 RMS 残差。闭式解验证循环采用 $x_1=0.7$，它是不同的代数验证设置。P3–P4 还已明确初值为确定实数，避免误将任意随机初始化后的 $x_n$ 称为 Gaussian。

## 5. 无噪声递减步长反例

取 $T=0,e_k=0,x_0=x_1=1$，直接将原公式中的 $s$ 换成 $s_k$。附录的速度递推正确。乘积尾和

$$
\sum_{n=i}^{\infty}\prod_{j=i+1}^n\frac{j}{j+\alpha}=\frac{i+\alpha}{\alpha-1}
$$

给出总下降量上界 $\alpha\sum s_k/[2(\alpha-1)]$。前缀自洽论证保证轨道始终为正。因此 $\sum s_k<2(\alpha-1)/\alpha$ 时有非零残差极限。该反例足以否定“只要某个形式上的 N6 级数有限，直接替换步长后的算法就保留原理论”。它没有排除经过重新设计的变步长算法。

## 6. AFP v1 的反例与边界

在该版本 AFP 中，$G\equiv0$、查询误差为零、$y^0=z^0=1$，给出所有迭代恒为 $1$。选择解 $x^\star=0$ 合法。取 $s=4,\gamma=1/2,\eta=1/10$，$t_{k-1}=13,t_k=14$，满足 Lemma 1 的 $s>1+\gamma$ 和 $t_k>2s$。

论文能量式 3 在此例为 $s^2(s-1)/(2\eta_{k-1}\gamma)$。按参数式 4，步长 $\eta_k$ 递减，所以该能量递增。代入得到

$$
\mathcal L_k-\mathcal L_{k+1}=\frac{8640}{13}-\frac{4800}{7}=-\frac{1920}{91}<0.
$$

式 5 的右侧在此例完全为零。反例因此成立。Appendix B.1 又将要求为正的 Young 参数选择为负值，与该符号冲突一致。

**可报告结论：** arXiv:2512.13547v1 的 Lemma 1 式 5 按印刷形式不成立。

**不可报告结论：** AFP 的最终路径定理已被反例否定；原复用 Fast KM 的 N6 定理因此具有新颖性；该论文的全部后续结论均不成立。以上三项均没有由此反例得到证明。

## 7. 复核后的研究边界

P1 是已给出证明的双查询基准。P2 是更强条件下的复用查询基准。P3–P4 揭示了查询复用的可验证效应。一般非线性复用算法在 N6 下的路径定理仍待证明。公开文献是否已经覆盖这一特定命题，需要另行完成新颖性判断。
